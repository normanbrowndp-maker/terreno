# TRAVEL-013 — безопасное сохранение проекта в GitHub

Дата: 2026-11-18. Основание: явное разрешение владельца загрузить текущий проект в `https://github.com/normanbrowndp-maker/terreno.git`. Оно заменяет прежнее ограничение «без remote/push» только для этого репозитория. Развёртывание и изменение функций не разрешены.

- **Цель:** сохранить исходный проект и всю достижимую историю ветки в GitHub, исключив секреты, локальные данные и временные файлы.
- **План реализации:** проверить Git/status/history/remote; проверить содержимое всех достижимых коммитов и index/worktree; проверить лицензии скиллов; добавить origin; отправить только текущую ветку обычным push; сравнить удалённые SHA и дерево с локальными.
- **Зависимости:** доступ GitHub к указанному репозиторию; существующие четыре коммита, gitignore и локальный Git. Пакеты приложения и БД для этой операции не требуются.
- **Критерии приёмки:** история не переписана; другие remote и чужие ветки не изменены; ветка и последний SHA доступны на GitHub; все исходники/документы/тесты/миграции/CI/AGENTS/пять проектных скиллов сохранены; секреты/generated/private paths отсутствуют в публикуемой истории; нет force/deploy.
- **Тесты:** `git status`, `log`, `fsck --full`, `ls-remote`; проверка `.gitignore` и staged blobs; отдельный scan истории; исходный secret scanner напрямую через Node; 170 исторических skill/lock hashes; GitHub REST refs/tree и сравнение paths/modes/blob SHA.
- **Риски:** репозиторий публичный; секрет в старом коммите требует остановки до публикации. Конкурентное изменение remote требует повторного чтения, без force. CI может автоматически стартовать по push; workflow содержит только проверки, не deploy.
- **Статус:** выполнено. Первая отправка и независимая удалённая сверка прошли; данный результат закрепляется дополнительным документационным коммитом без изменения исходников.

## Ограничение исторического gate

`verify_stage1.py` вне CI требует отсутствия любых remote — это правило прежнего локального этапа. После разрешённого добавления origin этот отдельный пункт ожидаемо не соответствует новой задаче. Gate не отключён и его код не изменён ради публикации. В CI условие «без remote» уже неприменимо; остальные проверки сохраняются. Адаптация локальной политики к явно разрешённому origin — отдельная следующая небольшая задача, если потребуется запуск полного локального gate.
