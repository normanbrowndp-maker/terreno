## Geographic snapshots

OpenStreetMap contributors, [ODbL1.0](https://opendatacommons.org/licenses/odbl/1-0/), retrieved2026-11-18; [copyright/attribution](https://www.openstreetmap.org/copyright). Three bounded snapshots: Firenze, Roma, Milano. Street geometry remains genuine; rendering selects longer street segments and larger buildings and rounds snapshot geometry to6 decimal degrees. This is an overview, not full navigation data. Source coordinates for city/place records are unchanged.

The Venice and Naples Overpass requests returned502/504/timeouts, including a smaller retry. No fictional street pattern replaces them. Those cities use real georeferenced point overviews explicitly labelled “no street data”. The runtime makes no external tile/provider request.

## Fonts and source design

Inter, JetBrains Mono and Playfair Display were downloaded from the official [Google Fonts repository](https://github.com/google/fonts), each with its OFL license in public/fonts. The PDF names Inter/JetBrains Mono; its serif is unnamed Type3 glyph data, so Playfair Display is an explicit visual approximation. The provided PDF is visual evidence, not a verified source of commercial businesses, opening times or photograph reuse rights.
