# Проблемы, риски и предложения

Дата: 2026-11-18. Все пункты ниже — результаты аудита или проектные риски; у пустого приложения не может быть подтверждённых runtime-багов. ISSUE — идентификатор наблюдения, работа выполняется по TRAVEL-задачам в ROADMAP. Сложность относительная: низкая — локальный шаг, средняя — несколько связанных частей, высокая — отдельная подсистема/исследование.

## Уточнения к требованиям владельца

1. Долговечность достигается понятными границами и миграциями, не максимальным числом технологий. Поэтому рекомендация — монолит с явными модулями и контрактами.
2. Последовательность «маршруты до авторизации» выполнима, но без обещания сохранения гостевого результата. Перенос через вход требует отдельного решения, иначе это источник потери данных.
3. Интеллектуальность не обязательно требует платной модели. Без качественных данных и validator LLM ухудшит доверие; сначала полезный алгоритм и объяснение ограничений.
4. Дизайн можно отложить, доступность и нормальную навигацию — нельзя. Они входят в функциональную приёмку первого UI.

Все предложения объясняют проблему, исправление, эффект, сложность и момент решения. Ни одно крупное расширение не было реализовано в рамках подготовки.
